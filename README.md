# TaskFlow

팀 작업 관리를 위한 경량 태스크 보드입니다. Express 기반 REST API와 정적 프런트엔드로
구성되어 있으며, 작업 생성·검색·상태 필터·상태 변경·삭제를 지원합니다.

## 실행

```bash
npm install
npm start        # http://localhost:3000
```

## 테스트

```bash
npm test
```

## 주요 기능

- **작업 목록**: 전체 작업을 카드 리스트로 표시
- **작업 생성**: 제목(필수), 담당자, 설명을 입력해 새 작업 추가
- **검색**: 제목/설명 키워드로 실시간 필터링
- **상태 필터**: 전체 / 할 일 / 진행 중 / 완료
- **상태 변경**: 카드에서 바로 상태 드롭다운 변경
- **삭제**: 카드에서 즉시 삭제

## API

| Method | Path             | 설명                              |
| ------ | ---------------- | --------------------------------- |
| GET    | `/api/health`    | 헬스 체크                         |
| GET    | `/api/tasks`     | 목록 조회 (`status`, `q` 쿼리)    |
| GET    | `/api/tasks/:id` | 단건 조회                         |
| POST   | `/api/tasks`     | 생성 (`title` 필수)               |
| PATCH  | `/api/tasks/:id` | 부분 수정 (제목/설명/담당자/상태) |
| DELETE | `/api/tasks/:id` | 삭제                              |

데이터는 인메모리 저장소에 보관되며 서버 재시작 시 초기 샘플 데이터로 돌아갑니다.
