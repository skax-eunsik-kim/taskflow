# TaskFlow

팀 작업 관리를 위한 경량 태스크 보드입니다. Express 기반 REST API와 정적 프런트엔드로
구성되어 있으며, 작업 생성·검색·상태 필터·상태 변경·삭제를 지원합니다.

## 실행

```bash
npm install
npm start        # http://localhost:3000
```

## 테스트

```bash
npm test
```

## 주요 기능

### 보드 (`/`)

- **작업 목록**: 전체 작업을 카드 리스트로 표시
- **작업 생성**: 제목(필수), 담당자, 설명을 입력해 새 작업 추가
- **검색**: 제목/설명 키워드로 실시간 필터링
- **상태 필터**: 전체 / 할 일 / 진행 중 / 완료
- **상태 변경**: 카드에서 바로 상태 드롭다운 변경
- **삭제**: 카드에서 즉시 삭제

### 프로젝트 (`/projects.html`)

- 프로젝트 생성/목록, 프로젝트 상세에서 작업 배정과 제외

### 통계 (`/stats.html`)

- 상태별 작업 수와 완료율 요약 카드
- 담당자별 작업 수
- 최근 활동 로그 (프로젝트/댓글 변경 이력)

### API 전용

- 작업 댓글 (`/api/tasks/:id/comments`), 태그 (`/api/tasks/:id/tags`, `/api/tags`),
  사용자 디렉터리 (`/api/users`)

전체 엔드포인트는 [docs/api.md](docs/api.md)를 참고하세요. 기여 방법은
[CONTRIBUTING.md](CONTRIBUTING.md)에 있습니다.

데이터는 인메모리 저장소에 보관되며 서버 재시작 시 초기 샘플 데이터로 돌아갑니다.
